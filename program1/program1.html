Text Styles

HTML (HyperText Markup Language) is the most basic building block of the web
it defines the meaning and structure of web content. Other technologies besides HTML are generally used to describe a web pages appearances/presentation(CSS) or functionality/behavior(JavaScript)


The HTML style attribute is used to style element, such as color font size and more.


Bold-The"b"tag in HTML is used to specify thebold text without any extra importance.


Italics-The "i" tag defines a part of text in an alternate voice or mood.The content inside is typically displayed in italic.


Underline-The "u"tag in HTML stands for underline,and its used to underline the text enclosed with in this "u" tag
